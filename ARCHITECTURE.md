# ClipPanel architecture

## Data flow

```text
Pasteboard changeCount → PasteboardMonitor → ClipboardCaptureService
→ Codable ClipboardPayload + SHA-256 → ClipboardStore / SwiftData
→ SearchEngine → ClipboardPanelController / SwiftUI panel
→ PasteService → restored pasteboard → prior application → Command-V
```

`ClipboardPayload` stores only value snapshots: item boundaries, type identifiers, and bytes. AppKit pasteboard objects never enter SwiftData or cross an actor boundary. `ClipboardStore` is main-actor isolated because SwiftData model objects and its `ModelContext` remain on that actor.

`ClipboardSchemaV2` adds optional library metadata, tags, collections, and smart filters over the original `ClipboardSchemaV1`. `ClipboardMigrationPlan` is supplied when opening the persistent store so future migrations add a schema/stage rather than relying on implicit model evolution.

## Important boundaries

- `PasteboardMonitor`, `ClipboardCaptureService`, `PasteService`, and `ClipboardPanelController` are main actor/AppKit boundaries.
- `SearchEngine` and `PanelPositioner` operate over pure values and have deterministic unit tests.
- `ClipboardRecord.payloadData` is an external SwiftData `Data` field; encrypted collection items replace it with AES-GCM ciphertext held on `ClipMetadata` and decrypt only for an explicit display, transform, paste, or archive action.
- Global-shortcut callers only use `ClipboardPanelController.toggle()`/`dismiss()`, keeping prior-app capture, focus, and panel placement private.

## Persistence behavior

The record hash is based on canonical type ordering within each item while retaining item ordering/boundaries. A matching hash is verified against encoded payload data before dedupe updates recency. Automatic cleanup removes only excess unpinned records. Pin state survives re-copying.

## Privacy behavior

Capture is limited to text, URL, HTML, RTF, PNG, TIFF, and file URLs. Common transient, concealed, autogenerated, and ClipPanel self-write markers are filtered before persistence. ClipPanel writes its own marker and feeds the resulting `changeCount` to the monitor, so restored payloads do not re-enter history.

The Library exports a versioned JSON archive or a password-encrypted AES-GCM envelope. The optional folder sync service only imports/merges and rewrites that encrypted archive when the user selects its folder and supplies the password. `ClipPanelAutomationRouter` is the single route for App Intents and the `clippanel://` URL API used by `clipctl`.
