# ClipPanel privacy

ClipPanel is local-only by design.

- History is stored by SwiftData in the standard macOS application-support location for the app’s bundle identity.
- Clipboard monitoring is explicitly enabled during onboarding or Settings; it can be paused from the menu bar.
- The app ignores `org.nspasteboard.TransientType`, `org.nspasteboard.ConcealedType`, and `org.nspasteboard.AutoGeneratedType` by default. These conventions do not guarantee every sensitive clipboard write is marked, so users should still use pause, ignored apps, and clear-history controls as needed.
- Auto-paste uses `CGPreflightPostEventAccess()` and `CGRequestPostEventAccess()` only after a user requests it. Text-caret panel placement is separately opt-in and requests Accessibility trust only from its Settings action.
- OSLog contains only operational metadata/state and never clipboard data, raw URLs, payload bytes, filenames from ignored apps, or search queries.
- Encrypted collections keep their payload bytes under a per-install AES-GCM key in the Keychain; normal collection metadata remains local SwiftData data.
- The app has no networking entitlement or network client code, analytics, accounts, remote logging, or crash-upload SDK. Optional folder sync is a user-initiated encrypted archive operation into a folder the user explicitly selects; [SYNC_THREAT_MODEL.md](SYNC_THREAT_MODEL.md) describes its boundaries.

Clear Unpinned History and Clear All History are destructive local actions. Clear All History requires a confirmation and removes pinned as well as unpinned records.
